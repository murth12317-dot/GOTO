# 三麻 ノーマル華4 オンライン対戦

友達とルーム番号で集まって遊べる三人麻雀です（ノーマル華4ルール）。
空いた席はCPUが入るので、1人や2人でも遊べます。

## ファイル

- `server.js` … サーバー（ルーム・席・通信）
- `game.js` … 対局のルール処理（点数・祝儀・華牌など）
- `public/index.html` … 画面
- `package.json` … 必要なライブラリ（express / socket.io）
- `gas/Code.gs` … 通算成績をスプレッドシートに記録する Apps Script（任意）

## Renderで公開する手順（4人麻雀と同じ流れ）

1. GitHubで新しいリポジトリを作り、このフォルダの中身をそのままアップロード
2. Renderで「New +」→「Web Service」→ そのリポジトリを選ぶ
3. 設定
   - Runtime：Node
   - Build Command：`npm install`
   - Start Command：`npm start`
   - Instance Type：Free
4. 「Create Web Service」で公開。数分で `https://〇〇.onrender.com` のURLができます

## 遊び方

1. URLを開いて名前を入れ「ルームを作る」
2. 友達にルーム番号（4桁）を伝える。友達は番号を入れて「参加」
3. 全員が「準備OK」を押したら、ルームを作った人が「開始」（足りない席はCPU。3人とも人間なら全員OKで自動開始）
4. 終局したら、誰でも「部屋に戻る」でメンバー画面に戻れます。次の対局も全員の準備OKから

## 注意

- LINEでリンクを開くと、自動でSafariなど外のブラウザで開き直します（LINEの中のブラウザでは音声が出ないため）
- 音声は、最初に画面のどこかをタップしたあとから鳴ります

- Renderの無料プランは、しばらく誰も使わないと眠ります。最初に開いたときは起動に1分ほどかかります
- オーラス（親が流れたら終わる局）で親が和了したときは、親が「やめる（終局）」か「続ける」かを選べます。流局は必ず続行です。親がCPU・代打のときは、トップならやめます
- 自分の番で2分操作がないと、自動でツモ切りしてCPUが代わりに打ちます。「復帰する」を押すか開き直せば本人に戻ります
- 対局中にページを閉じても、同じ端末で開き直せば同じ席に戻れます。戻るまでの間はCPUが代わりに打ちます
- 対局の途中経過はサーバーのメモリにあるので、Renderが再起動するとルームは消えます

## 通算成績をスプレッドシートに記録する（任意）

設定すると、半荘が終わるたびに結果が Google スプレッドシートに自動で書き込まれ、名前ごとの通算（半荘数・着順・祝儀）が計算されます。
Render が眠ったり再起動したりしても記録は消えず、ゲームの終局画面とルーム画面にも同じ通算が出ます。
設定しないときは、そのルームの中だけで通算を出します（ルームが消えるとリセット）。

1. Google スプレッドシートを新しく作る（名前は何でもOK）
2. メニューの「拡張機能」→「Apps Script」を開き、最初からある中身を全部消して `gas/Code.gs` の中身を貼り付ける
3. 6行目の `"ここに合言葉を入れる"` を、自分で決めた合言葉（英数字で長めに。例：`sanma-7f3k9q2x`）に書き換えて保存
4. 右上の「デプロイ」→「新しいデプロイ」→ 種類の歯車で「ウェブアプリ」を選ぶ
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
   - 「デプロイ」を押し、Google アカウントのアクセス許可を「許可」する（「安全ではないページ」と出たら「詳細」→「（安全ではないページ）に移動」）
   - 表示された「ウェブアプリ」の URL（`https://script.google.com/macros/s/…/exec`）をコピー
5. Render のサービスの「Environment」で環境変数を2つ追加して保存（自動で再デプロイされます）
   - `SHEET_URL`：4 でコピーした URL
   - `SHEET_SECRET`：3 で決めた合言葉
6. スプレッドシート右上の「共有」で、みんなに「閲覧者」として共有する（リンクを LINE に貼っておくと便利）

- 「記録」シートに半荘ごと・1人1行で書き込まれ、「通算」シートに名前ごとの合計が出ます
- 名前で合計するので、毎回同じ名前で入ってください
- 最初からCPUが入っている半荘は記録しません。人3人で始めた半荘は、途中で切断してCPUが代打になっても本人の名前で記録します
- ゲーム画面の通算も同じ扱いです（スプレッドシート未設定のときのルーム内の通算も、CPU入りの半荘は数えません）
- 記録の行を消したり直したりしたら、スプレッドシートのメニュー「三麻」→「通算を再計算」で通算に反映されます
- `gas/Code.gs` を書き換えたときは、「デプロイ」→「デプロイを管理」→ 鉛筆マーク → バージョン「新バージョン」で更新します（URL は変わりません）

## テスト

```
npm install
npm test
```

- `test/selfplay.js`：CPUだけで何半荘も続けて打たせて、止まる・エラー・点数や祝儀のずれ・同じ結果の出し直しがないかを確かめます
- `test/deal-check.js`：山を何万回もシャッフルして、配牌に偏りがないかをカイ二乗検定で確かめます
